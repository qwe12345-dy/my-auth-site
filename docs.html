创造工坊充值/打赏R币接口

亲爱的创作者，众所周知，想要获得R币使用的时候却总是只想着看广告，而广告每一天只有十次。呃，如果你是创作者的话，你可以应用上HTML代码中的充值接口，应用于打赏等等使用。

注意：最多只能充值或打赏 15000 R币，并且打赏之后会直接到账给开发者。使用的时候请在 Received user name/id 填上自己的名字或者ID，否则将无法打赏给你。

接口说明

项目说明
请求方式POST
接口地址/api/rc
内容类型application/json

请求参数

参数类型说明
amt整数打赏金额，范围 1~15000
tu字符串接收者用户名或用户ID

返回字段

字段说明
s是否成功（true/false）
m状态码（OK=成功，NB=余额不足，TU=用户不存在，SF=不能打赏自己）
nb打赏后你的剩余R币
tn接收者用户名

以下是代码

将下面的代码复制到你的游戏HTML中，修改 RECEIVER_NAME 为你的用户名或ID即可：

HTML + JavaScript 
<!-- 打赏按钮样式 -->
<style>
  .tip-btn{position:fixed;bottom:20px;right:20px;z-index:9999;
    padding:10px 18px;background:linear-gradient(135deg,#ffd700,#ffb300);
    color:#1a237e;border:none;border-radius:24px;font-size:14px;
    font-weight:700;cursor:pointer;box-shadow:0 4px 12px rgba(255,179,0,.4)}
  .tip-box{position:fixed;inset:0;background:rgba(0,0,0,.6);z-index:10000;
    display:none;align-items:center;justify-content:center}
  .tip-box.show{display:flex}
  .tip-card{background:#fff;border-radius:16px;padding:24px;width:80%;max-width:320px;text-align:center}
  .tip-card h3{margin-bottom:16px;font-size:18px}
  .tip-card input{width:100%;padding:12px;margin-bottom:12px;border:1px solid #ddd;border-radius:8px;font-size:16px;box-sizing:border-box}
  .tip-card button{width:100%;padding:12px;border:none;border-radius:8px;font-size:15px;font-weight:600;cursor:pointer;margin-top:6px}
  .tip-ok{background:linear-gradient(135deg,#4a7dff,#3b5fe0);color:#fff}
  .tip-cancel{background:#f0f0f0;color:#666}
</style>

<!-- 打赏按钮 -->
<button class="tip-btn" onclick="showTip()">💰 打赏作者</button>

<!-- 打赏弹窗 -->
<div class="tip-box" id="tipBox">
  <div class="tip-card">
    <h3>打赏作者</h3>
    <input type="number" id="tipAmt" placeholder="打赏R币数量（1-15000）" min="1" max="15000">
    <button class="tip-ok" onclick="doTip()">确认打赏</button>
    <button class="tip-cancel" onclick="closeTip()">取消</button>
  </div>
</div>

<script>
// 替换为你的用户名或ID
const RECEIVER_NAME = "你的用户名";

function showTip(){
  document.getElementById("tipBox").classList.add("show");
}
function closeTip(){
  document.getElementById("tipBox").classList.remove("show");
}
async function doTip(){
  const amt = parseInt(document.getElementById("tipAmt").value);
  if(!amt || amt < 1 || amt > 15000){
    alert("请输入1-15000之间的数量"); return;
  }
  try{
    const r = await fetch("/api/rc",{
      method:"POST",
      headers:{"Content-Type":"application/json"},
      credentials:"include",
      body:JSON.stringify({amt:amt, tu:RECEIVER_NAME})
    });
    const d = await r.json();
    if(d.s){
      alert("打赏成功！感谢支持");
      closeTip();
    }else{
      const msg = {NB:"R币余额不足",TU:"接收者不存在",SF:"不能打赏给自己",AR:"金额超出范围",NL:"请先登录"};
      alert(msg[d.m] || "打赏失败");
    }
  }catch(e){ alert("网络错误，请重试"); }
}
</script>
提示：玩家必须登录创造工坊账号并拥有足够R币才能打赏。打赏成功后R币会立即转入你的账户，可在钱包页面查看余额。

错误码含义

NBR币余额不足

SF不能打赏给自己
